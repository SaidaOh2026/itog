**Автор:**  Охова Саида

**Дата сдачи:** 30.04.2026
## Описание программы
** «Expense Tracker» - Приложение для отслежевания личных расходов с фильтрацией по категориям и датам, подсчётом суммы за период и сохранением данных в JSON.**
## Требования для запуска
- Python 3.10 или выше
- Библиотеки: 'datеtime', `tkinter` — для графического интерфейса, 'json', 'os'
## Примеры использования
1. Команда запуска `python main.py`
2. Введите сумму, категорию и дату.
3. Нажмите «Добавить расход».
4. Используйте фильтрацию и расчёт суммы за период.
5. Данные сохраняются в `expenses.json`.
